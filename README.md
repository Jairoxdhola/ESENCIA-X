### What is ESENCIA X

An **MCP server** that acts as a bridge between your **AI** and **Roblox**.  
Install the server, run the bridge in Roblox with Potassium, and from opencode  
you can control EVERYTHING with voice or text commands.

```
Your voice/text  ->  AI (opencode)  ->  MCP  ->  Potassium  ->  Roblox
```

### What you can do

| Action | Command |
|--------|---------|
| Fly | `execute_iy fly 100` |
| Walk through walls | `execute_iy noclip` |
| See players | `execute_iy esp` |
| Go to a player | `execute_iy goto noob123` |
| Freeze everyone | `execute_iy freeze all` |
| Building tools | `execute_iy btools` |
| God mode | `execute_iy god` |
| Invisible | `execute_iy invisible` |
| Execute Lua directly | `execute_lua` |
| Fire remote events | `fire_signal` |
| Create on-screen menus | `drawing_create` |
| And 20+ more tools... | |

> When installing Python, check the **"Add Python to PATH"** box.

### Installation

You only need 2 clicks:

**1.** Run `INSTALL.bat`  
**2.** Open `bridge.lua` in Potassium inside Roblox

```
No programming required. No manual configuration.
```

### Updates

Run `UPDATE.bat` to download the latest version automatically from GitHub.

---

### Troubleshooting

| Error | Cause | Solution |
|-------|-------|----------|
| `Roblox is not connected` | Bridge not running | Run `bridge.lua` in Potassium |
| `Connection closed (-32000)` | Port in use | Close all opencode windows and reopen |
| `Python is not installed` | Python missing | Install from python.org (check "Add to PATH") |
| `No such file: install.py` | File missing | Re-download the entire folder |
| Bridge spams "Port fail" | opencode is not open | Open opencode, the server starts automatically |
| `pip` doesn't work | Python incorrectly installed | Reinstall Python checking "Add to PATH" |
